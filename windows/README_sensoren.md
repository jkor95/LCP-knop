# LCP-sensoruitbreiding

Gebruik voor de bestaande werklaptop onder `%LOCALAPPDATA%\LCP\Werklaptop` de [actuele updateprocedure voor vier deursensoren](README_deursensoren.md).

De eerdere installer voor `C:\LCP` wordt niet meer gebruikt. De bestaande Zigbee-database, COM3-instelling en knopkoppeling blijven behouden.
