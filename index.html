1. Persoonlijke oproepcode

Alleen lokaal

Voeg precies dezelfde code toe in de ntfy-app op je iPhone. Kies een niet te raden code en deel hem niet openbaar.

2. Windows-vergrendelingstest

Geen installatie

Download een persoonlijk Windows-.cmd-bestand. Dat gebruikt curl.exe, standaard aanwezig op recente Windows-versies.

Vergrendeld testen: open het bestand → kies 2 → druk op Windows + L → de laptop probeert 20 seconden later een melding te sturen. Je laptop moet wakker blijven en internet hebben.

Deze test gebruikt géén toets op het vergrendelscherm. Een echte fysieke knop vereist later een eigen USB-/Zigbee-verbinding en achtergrondsoftware.

3. Testresultaten

Nog geen oproep verstuurdKlik op de groene knop na het instellen van je oproepcode.

    Het logboek op deze pagina bewaart alleen tests van deze browser. Oproepen uit het Windows-testprogramma staan in het opdrachtvenster en in ntfy op je iPhone.
